# RogSunk!
The JavaScript Version!

My interpretation of the classic arcade game: Sub Sunk
Wriiten to test what I had learn't on the JavaScript course I completed

This JavaScript version runs in 1920 x 1080 - if I get round to it will see if later versions can run on smaller resolutions


**Game Play**

Move your battleship so you can drop depth charges and try and hit the enemy sub!

Space - drop depth charge
A - move left
D - move right

**Features**

- Retro look and feel
- 4 levels of cloud movement!
- a secret shoal of deadly spindly killer fish!
- computer controller sub
- clouds wraps around teh screen
- authentic deluxe seabed
- boat rocks on the water!
- depth charge has realistic physics, drops quicker in air than water
- sound effects created by me
- background music is: Run of the mill by Judas Priest
